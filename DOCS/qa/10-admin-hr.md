# 10. 관리자 인사 — 부서 트리·부서장·유형 / 사원 목록·퇴직

- 대상 URL: `/admin/hr`(부서 탭), `/admin/hr/employees`(사원 탭)
- 필요한 계정: admin. 결과 확인용 user3(05b 기안 미리보기·08 조직도)
- 사전 조건: D1. **이 파일의 변경은 다른 테스트(결재선)에 영향을 준다 → 각 항목 끝의 "원복"을 반드시 수행.** 퇴직 처리는 **되돌릴 수 없다**(화면에 복직 기능 없음) → 실제 퇴직은 **일회용 확인용 사원**(환경 담당이 API로 만든 사원, 예: 로컬의 #2614)에만. 시드 계정(user1~9)은 모달을 열고 [취소]까지만

화면: 제목 "인사" / 설명 "부서장·부서 유형은 결재선을 만드는 기준입니다." / 탭 [부서 · 사원]

## 알려진 제한(버그 아님)

- 퇴직 취소(복직)·사원 등록·수정 화면이 없다(P2). 퇴직은 되돌릴 수 없다.

- 요구사항 4.1은 2026-11-09에 현재 서버 동작으로 갱신했다: **최상위 부서장 공석/재직 아님일 때만** 그 단계가 필요한 문서가 막힌다(작업 로그 #4).
- 직위·직급·직책 코드 목록 화면 없음(`refCodes` 플래그 꺼짐).
- 사원 탭의 상태·부서 필터는 URL에 남지 않는다(검색어만 남음).
