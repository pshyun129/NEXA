# 03b. 근태 신청 — 목록·신청(preview·상신)·상세·회수

- 대상 URL: `/attendance/requests`(`?year=&type=`), `/attendance/requests/new`(`?type=TIME_FIX|OVERTIME|HOLIDAY_SUBST&date=&subst=&fill=clock&start=&end=`), `/attendance/requests/:id`(목록 + 상세 Drawer)
- 필요한 계정: user3·user4(신청자), user5(결재자, 다른 Chrome 프로필)
- 사전 조건: D1·D8(Kafka). 같은 날짜·같은 유형 신청은 중복이 막히므로 날짜를 바꿔 가며 테스트. 테스트한 신청 #·문서 번호를 메모

흐름: 유형 → 입력 → **[확인](preview)** → 사유 → **[상신]** → 상세(결재 대기) → 팀장 승인 → Kafka 반영 → "승인 · 근태 반영 HH:mm:ss"
