## 알려진 제한(버그 아님)

- 로그인 잠금 시간이 서버 값(`retryAfterSeconds`)이 없으면 15:00부터 센다(gaps A6, 지금은 서버가 값을 줌).
- 같은 계정은 한 세션만: 두 번째 로그인 시 첫 세션은 **즉시가 아니라** 액세스 토큰이 끝나 재발급할 때 끊긴다(요구사항 1.1).
- 퇴직 처리된 사원이 이미 로그인해 둔 화면은 최대 15분 유지될 수 있다(퇴직 모달 안내 문구와 같음).
- 탑바 확인 대기 카운터를 눌러도 팝오버가 아니라 `/automation`으로 이동한다(팝오버 없음 — 설계 문서 2026-11-09 갱신으로 일치).
- 탑바 "반영 중 N" 카운터 없음(P2).
- 관리 모드 사이드바에 결재·자동화 카운터 없음(설계대로).
