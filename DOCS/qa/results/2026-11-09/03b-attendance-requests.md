## 발견 사항

1. **❌ 초과근무 딥링크의 start/end가 잘못되면 앱 전체가 흰 화면 (P2, 프론트)**
   - `/attendance/requests/new?type=OVERTIME&date=2026-11-12&start=18:00&end=20:00` → 콘솔 `TypeError: ….hour(...).minute(...).second is not a function`, 화면 전체가 비어 버림
   - 앱이 만드는 링크는 ISO 시각이라 평소에는 안 생기지만, 잘못된 쿼리 하나에 앱이 통째로 죽음(`TimeField.tsx` `timeFromIso`가 잘못된 값을 걸러내지 않음, 에러 경계 없음). `?month=abc`처럼 무시하고 빈 값으로 시작하는 게 맞음
2. **휴일대체 오류 문구에 내부 필드명 (P2, 근태 백엔드)**: "대상일(targetDate)은 휴일이어야 합니다." → 화면 라벨에 맞춰 "근무한 휴일은 휴일이어야 합니다." 정도로
3. **(참고) 내장 브라우저에서 TimePicker·Select 키보드 입력이 불안정**했으나 사람 조작에서는 문제 아닐 가능성이 큼(버그로 보지 않음)
