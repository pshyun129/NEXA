# 05a. 전자결재 — 결재함·문서 상세·승인/반려/전결/회수·단축키

- 대상 URL: `/approvals`(결재 대기), `/approvals?tab=drafted`(기안함), `/approvals?tab=all`(전체), `/approvals/:docId?…`(같은 탭·필터에서 문서 선택). 쿼리: `form`(양식), `status`(상태, 결재 대기 탭에는 없음), `q`(검색)
- 필요한 계정: user3(기안자) / user5(1단계 결재자) / user8(2단계, 본부장) / user9(3단계, 대표이사) — 기안자와 결재자는 **다른 Chrome 프로필**
- 사전 조건: 05b로 만든 문서들(권장 준비 세트)
  - 문서 A: user3 일반기안 금액 없음 → 결재선 user5 1단계(팀장 전결)
  - 문서 B: user3 일반기안 2,000,000원 → user5 → user8(본부장 전결)
  - 문서 C: user3 일반기안 아무거나 → 회수 테스트용
  - 문서 D: user3 일반기안 → user5가 반려(재기안 테스트용, 05b)
  - 근태 신청 문서(03b), 휴가 신청 문서(04), 자동화 문서(07, 가능하면)

## 알려진 제한(버그 아님)

- 참조함·처리함(완료) 탭 없음(P2).
