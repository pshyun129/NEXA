# 09. 관리 홈 (`/admin`)

- 대상 URL: `/admin`
- 필요한 계정: admin
- 사전 조건: D1·D4. "배포됐지만 사원에게 안 보임" 확인용으로 12-admin-builder에서 #1 [사원에게 노출]을 잠시 끄는 단계 포함(끝나면 원복)

화면: 제목 "관리 홈" → 카드 3개 "인사" / "업무 자동화" / "데이터 이관"

## 알려진 제한(버그 아님)

- 근태·급여·휴가 관리 숫자는 없다(관리자 API 없음/P2).
- 데이터 이관 카드는 바로가기만 있다(작업 목록 API가 develop에 없음, gaps B9).
- 숫자는 전체 사원·부서 목록을 받아 화면에서 센다.
