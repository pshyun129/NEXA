# 06. 급여 — 명세서·내 직급 급여·퇴직금 예상

- 대상 URL: `/pay`(`?year=YYYY&payslip=ID`)
- 필요한 계정: user3(명세서가 있는 계정 — 서버는 README S6에서 확인. 로컬 PC는 2026-09·10, 직급 G1 → 월 기본급 3,600,000원), user1(명세서 없음 → PAY_007), 직급 기본급이 없는 계정(PAY_002 확인용, 시드에 따라 G1 1호봉 외 직급은 계약 조회가 안 될 수 있음 **(확인 필요: 어느 계정)**)
- 사전 조건: D6(payroll-service 기동, 테스트 PC에 명세서 데이터 — 없으면 환경 담당이 admin으로 생성)

화면: 제목 "급여" → [내 직급 급여 | 퇴직금 예상] 2칸 → "급여명세서" 카드(연도 Select + 표)

## 알려진 제한(버그 아님)

- "내 직급 급여"는 개인 계약이 아니라 **직급 기본급** 기준이다(서버 API가 그렇게 줌).
- 실수령액 눈 아이콘 숨김 토글은 없다(만들지 미정 — 설계에도 "미정"으로 갱신). 0원 항목은 접지 않고 회색으로 표시한다(설계 문서 2026-11-09 갱신으로 일치).
- 급여 생성·관리자 명세서 목록 화면은 없다(P2). 명세서 데이터는 API로 생성.
- 서비스 기동 직후 몇 초간 게이트웨이 401이 날 수 있음(작업 로그) — 잠시 뒤 [다시 시도].
