# 02. 사원 홈 (`/`)

- 대상 URL: `/`
- 필요한 계정: user3(신청자, 휴가 데이터 있음), user5(결재자), user1(휴가 정책 없음), user4(데이터 적은 계정)
- 사전 조건: D1·D2. 결재 대기 표 확인용으로 user3이 user5에게 상신한 문서 1건 이상(05b 기안 또는 03b 근태 신청). 데모 1 확인은 user3 **어제** 출퇴근 로그(08:52 출근·18:32 퇴근) 시드(`POST /attn/admin/logs`, 환경 담당)

화면 구성(위 → 아래): 제목 "{이름}님, 안녕하세요" + 오늘 날짜(YYYY.MM.DD(요일)) → **처리할 일** → [오늘 근무 | 이번 주 근로 | 휴가 잔여] 3칸 → [결재 대기 (내 차례) | 내 최근 신청] 2칸 → (대기 건 있을 때만) **AI가 확인을 기다립니다**

## 알려진 제한(버그 아님)

- "AI가 확인을 기다립니다"에 워크플로 이름·대기 사유가 없다(gaps B5·B11). 설계 6.1은 사유 첫 줄 표시였음.
- 결재 대기 표에 "계산 중 n/m" 진행률이 없다(box=PENDING 한 번으로 받음 — 설계 문서 2026-11-09 갱신으로 일치).
- 출근 전 카드에 "어제 18:32 퇴근" 문구는 없다(설계 6.1과 다름).
- 홈 결재 대기 표는 30초마다 다시 읽으므로 처리 직후 잠깐 이전 행이 보일 수 있다.
