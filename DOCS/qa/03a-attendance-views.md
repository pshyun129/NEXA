# 03a. 근태 — 출퇴근 칩·일간·주간·월간·상태 이력

- 대상 URL: `/attendance`(일간, `?date=YYYY-MM-DD`), `/attendance/weekly`(`?week=월요일`), `/attendance/monthly`(`?month=YYYY-MM`), `/attendance/history`(`?from=&to=`)
- 필요한 계정: user3(근태 기록·신청 있음), user4(로테이션)
- 사전 조건: D1·D9. 근태이상·미승인 초과 확인용 과거 로그(시드 또는 실제 출퇴근)

근태 탭 순서: **일간 · 주간 · 월간 · 상태 이력 · 근태 신청**(근태 신청은 03b)

## 알려진 제한(버그 아님)

- 주간 표에 시간 막대가 없다(숫자만). 설계 6.4 와이어프레임의 막대는 주간 응답에 구간이 없어 그리지 않기로 함(gaps B3). 일간 Drawer 타임라인만 실제 구간.
- 퇴근 기록이 없으면 승인 초과·총 근로가 "—"/0(퇴근 후 계산). 오늘 시연에서 승인 초과가 0으로 보이는 것은 정상(로그 기록).
- 근무 상태 버튼 이름·종류는 서버 `ableStatusList`를 그대로 쓴다.
