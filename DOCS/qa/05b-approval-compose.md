# 05b. 전자결재 — 기안(일반·출장)·결재선 미리보기·재기안·참조자

- 대상 URL: `/approvals` 헤더 [기안하기](오른쪽 Drawer), 상신 후 `/approvals/{id}?tab=drafted`
- 필요한 계정: user3(기안), user5(결재·반려), user8·user9(상위 결재), user9(최상위 부서장 기안), user4(참조자 후보·권한 없음 확인)
- 사전 조건: D1(부서장·유형 시드 그대로 — 10-admin-hr에서 바꿨다면 원복 후)

로컬 API로 확인된 결재선(user3 기준, 작업 로그 #9): 일반 금액 없음 → **팀장 전결**(윤지호) / 2,000,000원 → **본부장 전결**(윤지호 → 임채원) / 20,000,000원 → **대표이사 결재**(윤지호 → 임채원 → 문태준) / 출장 국내 → 팀장 전결 / 출장 해외 → 본부장 전결. 금액 기준선은 화면에 하드코딩하지 않고 서버 응답을 그대로 그린다.

## 알려진 제한(버그 아님)

- 본문·첨부 입력이 없다(요구사항 6장 #8). 기안은 제목 + 금액/출장지만.
- 화면에서 직접 기안할 수 있는 양식은 일반기안·출장 두 가지뿐(휴가·근태·자동화 문서는 각 화면이 만든다).
- 결재선 순서 변경·결재자 추가는 없다(P2). 참조자만 편집.
- 결재 기안에 멱등 키(`requestKey`)는 쓰지 않는다(설계 7.2와 다름) — 버튼 로딩으로 중복 클릭만 막음.
- 폼 이탈 경고(`useUnsavedGuard`)는 기안 Drawer에 없다(빌더에만 있음).
