# 12. 관리자 자동화 빌더 — 캔버스·설정·검사·저장·테스트 실행·입력 폼·사원 노출·배포·버전

- 대상 URL: `/admin/builder`(목록), `/admin/builder/:id`(편집)
- 필요한 계정: admin. 결과 확인용 user3(사원 업무 자동화 목록·실행 폼, 07)

- **주의**: 배포는 같은 그래프여도 새 버전을 쌓는다. #1 그래프를 바꾸고 저장하면 시연 워크플로가 바뀐다 → 큰 변경은 #2에서 하고, 끝나면 환경 담당이 `node scripts/seed-demo-workflows.mjs`를 다시 돌려 원복(이름으로 찾아 덮어씀)

## 알려진 제한(버그 아님)

- 새 워크플로 만들기·복제·삭제·버전 되돌리기·자동 저장·노출 화면 여러 개 고르기·입력 폼 prefill은 없다(P2). 새 워크플로는 시드 스크립트/API로.
- 순서 경고는 노드별 입력 키를 프론트에 하드코딩한 규칙이라 새 노드(`excel_write`·`complete`·`free_prompt`·`doc_classify`)에는 경고가 없다.
- 서버 검사는 "파일 업로드 노드인데 입력 폼에 파일 칸 없음"을 보지 않는다 → 화면 경고로만 알린다.
- 새로고침 후에는 초안과 배포본을 비교할 수 없어 같은 초안 재배포 차단이 풀린다(버전 API에 그래프 없음).
- 이탈 경고는 링크 클릭·새로고침·탭 닫기만 막고 브라우저 뒤로가기는 못 막는다(BrowserRouter).
- 빌더·실행 API에 역할(ADMIN) 검사가 없다(서버 보안 갭, gaps B11) — 메뉴만 관리자 전용.
- 설계 #18 "시연 워크플로는 배포 후 초안 수정 금지"는 실행 화면이 단계 목록으로 바뀌어 이제 필요 없다(설계·요구사항 문서에서 폐기, 2026-11-09).
