## 알려진 제한(버그 아님)

- 결재자(user5)는 휴가 결재 문서에서 **날짜를 볼 수 없다**: 제목 "휴가 신청" 고정, 속성 "휴가 일수 n일"만(gaps B18). [원본 신청 보기]는 기안자에게만.
- 휴가 신청 자체의 회수 API가 없어 **결재 문서 회수**로 처리한다 → 반영은 Kafka 경유라 몇 초 "반영 중".
- 신청 화면에 결재선 미리보기가 없다(설계 6.3 헤더의 "결재선: 팀장 → (5일 이상 본부장)"과 다름). 201 성공 시 결과 카드 대신 상세 Drawer로 이동(설계 문서 2026-11-09 갱신으로 일치). 결재선 미리보기는 만들지 미정.
- 목록 응답에 날짜가 없어 보이는 페이지(10행)만 상세를 따로 읽는다 → 날짜 칸이 잠깐 "…".
- 시간 단위(HOUR) 휴가는 서버가 아직 받지 않아 종일/오전/오후만 고를 수 있다.
- 휴가 데이터는 user3·4·5만 있다. 다른 계정은 LEAVE_010 안내가 정상.
- 관리자 휴가 관리 화면 없음(P2. 로컬은 `/leaves/admin/**`가 503 LEAVE_017, 서버는 확인 안 함).
