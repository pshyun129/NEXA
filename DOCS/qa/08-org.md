# 08. 조직도 (`/org`)

- 대상 URL: `/org`
- 필요한 계정: user3(개발팀 사원), user5(개발팀 팀장 — 본인 단계 건너뜀), user6(영업팀 팀장 — 영업본부 공석), user9(대표이사), 퇴직자 1명 이상(10-admin-hr 퇴직 처리 또는 로컬 #2614)
- 사전 조건: D1 부서장·유형 시드 그대로(10-admin-hr에서 바꿨다면 원복)

화면: 제목 "조직도" → 왼쪽 "내 결재 라인"(또는 "{이름}의 결재 라인") / 오른쪽 "사원 검색"

## 알려진 제한(버그 아님)

- 조직 전체 트리(부서 계층 그림)는 사원 화면에 없다. 사원 메뉴 조직도는 "결재 라인 + 사원 검색"으로 정했다(요구사항 4.1). 트리는 관리자 인사 화면에만.
- 결재 라인은 공석·본인 단계를 건너뛰는 규칙만 보여 주고, 실제 몇 단계까지 올라가는지는 문서 종류·금액에 따른다(미리보기가 최종).
- 사원 목록은 서버가 한 번에 전체를 주고 화면에서 검색한다(서버 검색 없음).
